# Actualist for Android (experimental)

An experimental native Android port of [Actualist](https://github.com/sporez/actualist),
a local-first client for [Actual Budget](https://actualbudget.org). Kotlin, Jetpack
Compose, Material 3 and SQLite.

**This is a personal engineering experiment, not a release.** It is not published,
has no production signing, and must not be pointed at a real budget. All tests and
the bundled demo budget use synthetic data only.

## Layout

| Module | Contents |
|---|---|
| `core/` | Pure Kotlin/JVM engine: Actual's HLC timestamps, merkle trie, protobuf sync wire format, AES-256-GCM encryption, the SQLite budget database with CRDT apply and an atomic local-write outbox, envelope/tracking budget math, transactions, rules, schedules, reconciliation, CSV, the sync engine and the Actual server client. Runs in JVM unit tests and on Android through the bundled SQLite driver. |
| `app/` | Jetpack Compose + Material 3 Android app on top of `core`. |

The reference implementation and the exact commit this port follows are in
[`REFERENCE.md`](REFERENCE.md). Engineering status is in [`PROGRESS.md`](PROGRESS.md);
deliberate and inherited differences from Actual are in [`KNOWN_DIVERGENCES.md`](KNOWN_DIVERGENCES.md).

## Feature status

"Oracle" means the behavior is replayed against Actualist's pinned fixtures generated by
running Actual v26.10.0 itself on synthetic data.

| Area | Status | Verification |
|---|---|---|
| Demo budget (no server, no credentials) | Done | JVM + emulator UI tests |
| Budget screen: months, To Budget, assign, move, cover, hold, rollover, add/hide categories | Done | BudgetMonth oracle (80 cases), Holds oracle (14), Tracking contract (36), UI tests |
| Tracking (report) budgets | Read + assign | Oracle cases; UI summary card only |
| Transactions: list, search, create, edit, delete, transfers, splits (create + edit) | Done | Transactions oracle (21), split/edit unit tests, UI tests |
| Rules: engine (conditions, ranking, actions, formulas, splits) | Done, read-only UI | Rules oracle (245 cases); rule preview UI test |
| Schedules: recurrence, status, post, skip, complete, delete | Done, no editor | Schedules oracle (136 + 49 + 66 cases) |
| Accounts: list, balances, add, close/rename (core) | Done | Unit + UI tests |
| Reconciliation: cleared balance, adjustment, lock/unlock | Done | Unit tests from Actualist's reconciliation oracle; UI test |
| Payees: rename, merge | Done | Unit test |
| Reports: net worth, cash flow, spending by category | Done | UI screenshots; logic from Actualist's report reads |
| CSV export (Actual's format) / import (exact-duplicate skipping) | Done / partial | Encoder cases from Actualist; round-trip test |
| Server: password sign-in, budget list, (encrypted) download, sync with confirmation, merkle repair | Done | Multi-device sync tests; HTTP end-to-end on JVM and on the emulator against a loopback server |
| Budget templates, bank sync, OpenID login, rule/schedule editors, account groups, widgets | Not ported | — |

## Building

All builds and tests run in GitHub Actions; nothing Android-specific needs to be
installed locally.

- **Build and unit test** (`.github/workflows/build.yml`): every push. Builds the
  debug APK, runs the JVM tests, uploads the APK (`actualist-android-debug-apk`)
  and test reports.
- **Android emulator tests** (`.github/workflows/emulator.yml`): manual dispatch
  at milestones. Boots an API 34 emulator, installs the APK, cold-launches it, runs
  the instrumentation/Compose UI suite (including a sign-in, download and sync flow
  against a loopback Actual server inside the test process), kills the app process
  to check the selected budget reopens, and uploads screenshots, logcat and results
  (`emulator-results`).

With a local JDK 17 and Android SDK, `./gradlew :core:test :app:assembleDebug`
works as usual.
