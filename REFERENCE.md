## Reused test vectors and fixtures

- Merkle vectors from upstream `merkle.test.ts`, as replayed by Actualist `MerkleTrieTests.swift`.
- Budget-month oracle contract (`ActualistTests/Fixtures/ActualCore26_10_0/BudgetMonth/`), 86 cases generated by running Actual v26.10.0's `budget/*` handlers on synthetic data.
- Crypto vectors generated locally with Node's `crypto` (`tools/crypto-vectors.mjs`), synthetic inputs only.

## Actual source consulted

For behavior Actualist does not implement (the bulk month actions: copy previous
month, set zero, 3-month average, copy until year end, cover overbudgeted), the
pinned Actual source itself was read: tag `v26.10.0`, commit
`2bebdbaae0b701120a8cad9d56aafd64fa04c577`,
`packages/loot-core/src/server/budget/actions.ts` (MIT). It is the same build the
parity oracle was generated from, so those ports are checked by the oracle's
recorded cases. The same source was also read for undo (`server/undo.ts`),
transfer updates (`server/transactions/transfer.ts`), category learning
(`server/transactions/transaction-rules.ts`, `updateCategoryRules`) and the
server's SimpleFIN routes (`sync-server/src/app-simplefin`).
